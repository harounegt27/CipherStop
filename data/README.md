The original RanSMAP dataset is not included in this repository because of its large size.

To run the EDA notebook with the original dataset, access it through Kaggle:

- **Dataset:** RanSMAP — 2024 Ransomware Behavioral Features
- **Source:** [Kaggle dataset](https://www.kaggle.com/datasets/hiranomanabu/ransmap-2024-ransomware-behavioral-features)

**Note:** The dataset is intended to be accessed directly through Kaggle. Running the notebook locally requires access to the dataset files.
